# Yubo Zhang

Academic homepage of Yubo Zhang (张玉波), Associate Professor at Minjiang University ([Minjiang Collaborative Center for Theoretical Physics](https://wdxy.mju.edu.cn/llwlxzzx/)).

**Live site:** https://yubodrzhang.github.io

The site is built with [Academic Pages](https://github.com/academicpages/academicpages.github.io), a Jekyll theme for academic websites, and is published with GitHub Pages from the `master` branch.

## Site content

* Homepage, including the CV sections: `_pages/about.md`
* Navigation: `_data/navigation.yml`
* Publications: one Markdown file per paper in `_publications/`
* Site-wide settings, including the repository name: `_config.yml`

Talks, teaching, portfolio items, and blog posts are not listed because they are not on the CV. Those collections are turned off in `_config.yml`.
